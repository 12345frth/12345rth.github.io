AI生成项目需求说明（日志管理系统）
一、项目目标

请你生成一个完整可运行的 Web 项目，项目名称为：日志管理系统（Log Management System）

该系统用于：

收集日志
存储日志
查询日志
使用AI分析日志异常
二、技术要求（必须遵守❗）

请严格按照以下技术栈生成：

前端
使用：React（或 Vue3）
UI框架：Ant Design（或 Element Plus）
页面需包含完整布局（侧边栏 + 顶部导航）
后端
使用：Python（Flask 或 FastAPI）
提供RESTful API
数据库
使用：MySQL 或 SQLite
必须包含建表SQL
AI能力
使用简单可实现方式（不要空谈）：
基于规则 或
调用大模型API（模拟也可以）
三、核心功能（必须全部实现）
1. 用户系统
用户注册
用户登录（JWT认证）
不同角色（管理员 / 普通用户）
2. 日志采集

支持以下方式：

手动输入日志（前端表单）
API提交日志（POST接口）

日志字段：

时间
日志级别（INFO / WARN / ERROR）
内容
来源
3. 日志管理

必须实现：

日志列表展示（分页）

时间范围
关键词
日志级别
4. AI日志分析（重点🔥）

实现一个“看起来真的在用AI”的功能：

至少包含：

自动识别 ERROR 日志
标记“异常日志”
简单分析原因（可用规则模拟）

👉 示例输出：

“检测到数据库连接失败，可能原因：数据库未启动”
5. 数据可视化

至少包含：

日志数量趋势图（按时间）
ERROR占比图
四、页面要求

必须包含以下页面：

登录页
首页（统计信息）
日志列表页
日志分析页（展示AI结果）
五、接口设计（必须生成）

请输出完整API，例如：

POST /login
POST /logs
GET /logs
GET /logs/analysis

每个接口要包含：

请求参数
返回示例
